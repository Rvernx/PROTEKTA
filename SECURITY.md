# Security Policy

## Supported Versions
At this time, only the latest version on the `main` branch of PROTEKTA is supported with security updates. 

| Version | Supported          |
| ------- | ------------------ |
| Main    | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you discover a security vulnerability within the PROTEKTA pipeline or its associated AI modules, please report it via email directly to the project maintainer. 

* **Email:** [Your Professional Email Address]

Please include the following details in your report:
1. A description of the vulnerability.
2. Steps to reproduce the issue.
3. The potential impact of the vulnerability.

I treat security reports with the highest priority and will acknowledge receipt of your vulnerability report within 48 hours. I will keep you updated on the progress of the remediation.
